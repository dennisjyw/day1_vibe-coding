# 練習 1：從校務現象到可驗證問題

## 問題起點

校務會議上，主管問：「註冊率近年怎麼變化？接下來怎麼辦？」
這句話混合了現象、原因與決策。第一步不要預設註冊率持續下降，也不要做圖表或寫程式，而是把問題拆成可由資料回答的部分。

## 可直接貼入 Codex 的 Prompt

```text
Context
先閱讀 data/data_dictionary.md。資料不對應任何真實學校或學生。

Task
1. 把「註冊率近年怎麼變化？接下來怎麼辦？」整理成 problem-brief.md。
2. 先區分目前 CSV 可以回答、需要補充資料，以及不能僅靠描述性資料回答的問題。
3. 提出至少 5 個可驗證假設；每個假設都要列出需要看的指標、可能反證、
4. 目前資料是否足夠，以及假設成立後仍需查證的下一步。

Constraints
- 先定義問題，不寫程式、不做圖表。
- 不修改原始 CSV。
- 不把合成資料描述成真實校務結果。
- 不把相關性寫成因果性。
- 不捏造資料欄位或外部事實。

Acceptance Criteria
- 現象、研究問題、假設、反證與行動彼此分開。
- 每個假設都能由現有資料或明確列出的後續資料驗證。
- 清楚列出目前資料限制。
- 輸出檔名為 problem-brief.md。
```

## 人工驗收

- 有區分「看見什麼」與「為什麼發生」
- 有列出目前 CSV 可以與不能回答的問題
- 至少 5 個假設都有指標與可能反證
- 沒有直接宣稱原因已被證明
- 沒有出現真實個資、真實學校或未提供的欄位

完成後可對照 `examples/problem-brief.md`，但仍以自己的任務輸出與驗收結果為準。
