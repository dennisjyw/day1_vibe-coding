# 練習 3：分析報告

## 可直接貼入 Codex 的 Prompt

```text
Context
使用 data/data_dictionary.md、data/ir_registration_synthetic.csv，以及上一輪已驗證的資料探索結果。報告讀者是假設要在校務會議前檢查資料的分析人員。

Task
產生 analysis.md，內容包含：
1. 分析目的。
2. 資料來源與品質檢查。
3. 報到率、註冊率、報到後註冊率與休學率的分子、分母。
4. 按年度、系所與招生管道比較。
5. 值得進一步驗證的現象。
6. 每個現象的可能假設、反證與所需補充資料。
7. 資料限制與下一步。

Constraints
- 所有比率使用加總後的分子除以加總後的分母，不直接平均各列百分比。
- 不修改原始 CSV。
- 描述性統計不等於因果解釋。
- 不把合成資料當成真實政策證據。
- 不新增真實個資或捏造來源。
- 小數百分比統一四捨五入到 1 位。

Acceptance Criteria
- 每個主要數字可回溯到原始欄位與計算方式。
- 年度、系所、招生管道的比較口徑一致。
- 觀察、解釋、假設與建議彼此分開。
- 明確列出資料不足與未驗證項目。
- 輸出檔名為 analysis.md。
```

## 人工驗收

- 指標定義清楚且分母一致
- 使用總分子／總分母，而非平均列百分比
- 年度與分組比較可回溯
- 觀察、假設與結論分開
- 有反證、資料限制與下一步

完成後可對照 `examples/analysis.md`，但必須先自行重算至少一個年度與一個分組的指標。
