# 完成範例使用說明

本資料夾提供講師示範與學員自我檢查用的完成範例。

目前範例對應的合成 CSV 為 342 列、11 欄，涵蓋 2021–2026 學年度、6 個學院、19 個系所與 3 個招生管道。

- `problem-brief.md`：示範如何把模糊現象拆成可驗證問題。
- `analysis.md`：示範如何從合成 CSV 建立可追溯的描述性分析。

使用原則：

1. 先完成自己的練習，再閱讀範例。
2. 範例中的數字只對目前的合成 CSV 有效，不代表真實學校或政策結果。
3. 即使範例已提供數字，仍要從原始 CSV 重算至少一個年度與一個分組。
4. 範例不是唯一答案；只要資料口徑、證據、限制與驗收完整，可以有不同寫法。
